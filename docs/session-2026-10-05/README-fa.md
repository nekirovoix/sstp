# سورس و مستندات جلسه اتصال SSTP و Kill Switch

این پوشه مکمل پروژه اصلی SSTP Deploy Manager است؛ کد برنامه اصلی، ابزار Quick Connect و مستندات قبلی را جایگزین نمی‌کند. سورس‌های موجود در جلسه بدون تغییر منطق نگهداری شده‌اند. فایل‌های اجرایی ویندوز در محیط Linux اجرا یا تست نشده‌اند؛ نتایج زیر گزارش کاربر در Windows است.

## فایل‌ها

- `scripts/Connect-rus-v1.3.ps1`: آخرین Launcher با گزارش اتصال موفق؛ استفاده از رابط بومی rasphone و SendKeys.
- `scripts/SstpKillSwitch-v1.2.ps1`: آخرین Kill Switch؛ Status، Enable، Disable و EmergencyReset.
- `archived/`: نسخه‌های قبلی برای بررسی تاریخچه، نه نصب و استفاده.
- `docs/OPERATIONS-fa.md`: نصب، شورتکات، تست و بازیابی.
- `docs/SESSION-fa.md`: خلاصه تصمیم‌ها، خطاها و نتایج واقعی جلسه.
- `docs/SECURITY-fa.md`: محدودیت‌ها و هشدارهای امنیتی.
- `SHA256SUMS.txt`: هش فایل‌های PowerShell.

## وضعیت نهایی

Launcher v1.3 برای پروفایل `rus` گزارش `Connected successfully` داد. Kill Switch v1.2 روی یک پروفایل SSTP دیگر آزمایش شد: در حالت متصل تست TCP 443 به 1.1.1.1 موفق و بعد از قطع VPN ناموفق شد. نتیجه اتصال مجدد در حالت قفل و بازیابی نهایی Disable در گفتگو ثبت نشده است. این آزمایش گواه نبود همه نشت‌ها، پوشش IPv6 یا قفل‌بودن همه برنامه‌ها نیست.

نام میزبان و IP سرور آزمایش، نام حساب ویندوز، تصاویر و فایل‌های وضعیت شخصی منتشر نشده‌اند. نام نمونه `rus` در سورس اصلی حفظ شده؛ رمز یا اعتبارنامه به این بسته اضافه نشده است. سورس‌های جلسات پیشین که فایل مستقل آن‌ها در دسترس نبود بازسازی یا جعل نشده‌اند.
