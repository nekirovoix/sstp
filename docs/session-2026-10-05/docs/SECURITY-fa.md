# محدودیت‌های امنیتی نسخه‌های جلسه

این بسته آرشیو سورس و وضعیت واقعی است، نه Kill Switch ممیزی‌شده و تضمین‌شده بدون نشت.

- DefaultOutboundAction=Block، قوانین Allow موجود برای برنامه‌ها را خنثی نمی‌کند. بنابراین برنامه دارای قانون Allow ممکن است بیرون VPN ارتباط داشته باشد؛ تست فقط یک مقصد کافی نیست.
- DNS UDP/TCP 53 به resolverهای شناسایی‌شده روی هر رابط اجازه داده می‌شود؛ DNS خارج تونل عمداً ممکن است و ادعای zero DNS leak درست نیست.
- اجازه TCP 443 به IP سرور به یک سرویس/برنامه خاص محدود نیست. هر برنامه می‌تواند از این استثنا استفاده کند.
- اجازه RemoteAccess برای همه رابط‌های این نوع است، نه فقط پروفایل انتخاب‌شده. DHCPv4/v6 نیز استثنا است.
- فقط IPv4 سرور Resolve می‌شود. IPv6 اینترنت، AAAA سرور و ارتباط برنامه‌ها از IPv6 مستقل تست نشده‌اند.
- Enabled=False، Group Policy یا قواعد Block/Allow دیگر می‌توانند نتیجه را تغییر دهند. اسکریپت پروفایل خاموش را فعال نمی‌کند.
- چند SSTP متصل، تغییر IP سرور، DNS جدید، تعویض شبکه یا انتخاب پروفایل دیگر ممکن است نیاز به بازپیکربندی داشته باشند.
- وضعیت ذخیره‌شده JSON دارای اعتبارنامه نیست ولی اطلاعات شبکه دارد؛ منتشر نکنید. اعتبارسنجی، نوشتن اتمیک، ACL اختصاصی و سازگاری مهاجرت schema v1.1 به v1.2 پیاده نشده‌اند. وضعیت قدیمی را با نسخه خودش بازیابی کنید؛ فایل وضعیت را بی‌دلیل پاک نکنید.
- شکست Enable تلاش به بازیابی پیش‌فرض‌ها می‌کند، اما عملیات در catch نیز ممکن است شکست بخورد. در Enable مجدد، قوانین قبلی گروه بازسازی/عیناً بازیابی نمی‌شوند. عبارت «تراکنشی» به معنای تضمین اتمیک نیست.
- Disable تنها پیش‌فرض خروجی ذخیره‌شده و قوانین گروه خود را مدیریت می‌کند، نه همه سیاست‌های فایروال. تغییرات هم‌زمان مدیر سیستم می‌توانند با آن تداخل داشته باشند.
- EmergencyReset دقیقاً Allow را تحمیل و وضعیت را حذف می‌کند؛ فقط اضطراری و با آگاهی از ازبین‌رفتن سیاست قبلی.
- اتوماسیون Launcher مبتنی بر AppActivate/SendKeys است. تغییر فوکوس ممکن است Enter را به پنجره دیگر بفرستد؛ پنجره UAC/دیالوگ متفاوت قابل تضمین نیست.
- اجرای اسکریپت قابل‌ویرایش با Administrator خطر دارد؛ فایل Kill Switch را در مسیر مناسب با ACL بررسی‌شده نگه دارید. بازکردن مجوز نوشتن ریشه C برای همه کاربران توصیه نمی‌شود.
- گذرواژه، کلید خصوصی، state زنده، لاگ شخصی و transcript کامل را Commit نکنید. کد آرشیوی ممکن است ایراد داشته باشد و فقط مرجع تاریخی است.

برای اعتماد امنیتی بالاتر: بازطراحی سیاست محدود به رابط/سرویس، مدیریت قوانین Allow موجود بدون ازبین‌بردن تنظیمات کاربر، جلوگیری از DNS خارج تونل، پوشش IPv6 و تست خطا/بازیابی/ری‌استارت لازم است. این بهبودها در نسخه حاضر اجرا نشده‌اند.
