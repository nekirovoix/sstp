## ساخت فایل در C

ابتدا icacls پیش از ساخت پوشه اجرا شد، سپس کپی Prompt به‌جای دستور و کاراکترهای اضافه باعث خطای دستور شد. بعد از رفع آن، حساب کاربر Modify داشت، اما New-Item در ریشه C خطای `A required privilege is not held by the client` داد. ACL گزارش‌شده شامل برچسب High ارث‌پذیر برای فایل‌ها و همچنین Full Control گسترده برای Users و Authenticated Users بود.

برچسب ارث‌بری ریشه تغییر داده شد و ایجاد فایل user-test.txt موفق شد. از خروجی نهایی معلوم نیست آزمایش در پنجره ادمین انجام شده یا معمولی؛ موفقیت Explorer معمولی مستقل تأیید نشده است. این تغییرات راهنمای توصیه‌شده نصب نیستند. ACL کل C را بازگشتی تغییر ندهید؛ کاهش امنیت کل درایو، غیرفعال‌کردن UAC یا مالکیت‌گیری بازگشتی مناسب نیست. تنظیمات فعلی باید با بکاپ معتبر/مدیر سیستم بررسی شوند، نه با ریست حدسی مجوزهای ویندوز.

## Kill Switch

- v1.1 بررسی شد: Disable بدون وضعیت، سه پروفایل را Allow می‌کرد؛ به آرشیو منتقل شده است.
- v1.2 وضعیت قبلی را ذخیره می‌کند، هنگام خطا تلاش به Rollback دارد و EmergencyReset را جدا کرده است. این بازیابی اتمیک/تضمین‌شده نیست.
- قبل از Enable: سه پروفایل Enabled=True و DefaultOutboundAction=NotConfigured، قوانین ABSENT و وضعیت ABSENT.
- پس از Enable: سه پروفایل Block و 6 قانون PRESENT، پروفایل SSTP فعال به‌صورت خودکار انتخاب شد. نام/IP/دامنه سرور آزمایش در مستند عمومی حذف شده‌اند.
- تست متصل: مقصد 1.1.1.1 پورت 443، InterfaceAlias پروفایل VPN، آدرس منبع تونل خصوصی، TcpTestSucceeded=True.
- تست بعد از قطع: `WARNING: TCP connect to (1.1.1.1 : 443) failed` و `WARNING: Ping to 1.1.1.1 failed with status: 11050`. خروجی نهایی False در متن ارسال‌شده نبود؛ شکست TCP همان مقصد گزارش شد.
- نتیجه اتصال مجدد، Disable نهایی، IPv6، DNS leak، راه‌اندازی مجدد و همه برنامه‌ها هنوز گزارش/تأیید نشده‌اند.
