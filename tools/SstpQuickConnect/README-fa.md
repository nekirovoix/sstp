# SSTP Quick Connect

ابزار مستقل اتصال سریع به پروفایل SSTP ذخیره‌شده ویندوز.

## استفاده

1. فایل‌ها را از ZIP خارج کنید و کنار هم نگه دارید.
2. نام دقیق پروفایل VPN را در `profile.txt` بنویسید؛ مقدار پیش‌فرض `rus` است.
3. یک بار `SstpQuickConnect.exe` را اجرا کنید. برنامه VPN را متصل و میانبر `Ctrl+Alt+V` را ثبت می‌کند.
4. از دفعات بعد با فشردن `Ctrl+Alt+V` اتصال VPN انجام می‌شود و برنامه خودکار بسته می‌شود.

این ابزار رمز را ذخیره نمی‌کند و از اعتبارنامه‌ای استفاده می‌کند که قبلاً در Windows VPN/RAS ذخیره شده است.

## فرمان‌های اختیاری

- `SstpQuickConnect.exe --install-hotkey` فقط میانبر را نصب می‌کند.
- `SstpQuickConnect.exe --remove-hotkey` میانبر را حذف می‌کند.
- `SstpQuickConnect.exe --disconnect` اتصال را قطع می‌کند.

فایل اجرایی و `profile.txt` را پس از نصب میانبر جابه‌جا نکنید؛ در صورت جابه‌جایی، برنامه را یک بار دوباره اجرا کنید تا مسیر میانبر اصلاح شود.
